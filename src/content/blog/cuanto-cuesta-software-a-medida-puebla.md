El precio de un sistema a medida depende de lo que debe resolver. No cuesta lo mismo una aplicación para recibir solicitudes que una plataforma con varios módulos, perfiles de usuario e integraciones.

En Puebla, una **web app personalizada puede iniciar desde $15,000 MXN**. Para un sistema interno que centraliza información y automatiza procesos, el precio inicial es **$20,000 MXN**. Son precios de partida: la cotización final se define después de entender el proceso y acordar el alcance.

## Qué determina el costo

### 1. El proceso y sus reglas

Primero hay que entender qué información entra, quién la revisa, qué decisiones se toman y cuál es el resultado esperado. Un formulario con un flujo sencillo tiene un alcance distinto a un proceso con aprobaciones, excepciones y varios responsables.

### 2. Los módulos necesarios

Un sistema puede empezar con una función concreta y crecer después. Por ejemplo, una primera versión podría registrar solicitudes; más adelante podría sumar un tablero, avisos o un módulo de seguimiento. Definir qué es indispensable para la primera versión ayuda a priorizar el presupuesto.

### 3. Usuarios y permisos

Si distintas personas o áreas necesitan ver o modificar información diferente, el sistema debe definir perfiles y permisos. La cantidad de usuarios por sí sola no determina el precio, pero las reglas de acceso y responsabilidad sí forman parte del alcance.

### 4. Integraciones y reportes

Conectar el sistema con servicios externos, importar datos existentes o generar reportes agrega trabajo de análisis y pruebas. Conviene incluir solo las integraciones que realmente resuelven una necesidad del proceso.

## Cómo definir una primera versión

Antes de construir, ayuda responder estas preguntas:

- ¿Qué tarea repetitiva o problema necesita resolverse primero?
- ¿Quién captura la información y quién la consulta?
- ¿Qué datos deben quedar registrados?
- ¿Qué resultado debe poder revisar el equipo al final?
- ¿Qué puede esperar para una segunda etapa?

Con esas respuestas se puede describir una primera versión, acordar sus módulos y estimar el trabajo con menos incertidumbre. El proceso puede incluir diagnóstico, diseño, prototipo, desarrollo, pruebas con datos representativos e implementación.

## Qué incluir en una solicitud de cotización

Para recibir una propuesta comparable, describe el proceso actual, las personas que participan, los datos que deben registrarse y las funciones que son indispensables para la primera versión. Añade las integraciones conocidas y señala qué podría esperar a una etapa posterior.
